01

The demo was never the hard part.

Nobody's AI programme fails because the model was weak. It fails in the gap between a notebook and a Tuesday afternoon — where the data will not join, the permissions do not exist, and nobody owns the result.

AI programmes fail at the seams.

Six of them. Every one an engineering problem rather than a research problem — which is the entire reason this firm exists.

The dataSystems that will not join. Contracts nobody wrote. Lineage nobody can trace.
The integrationA model that works in a notebook and has no route into the process that needed it.
The handoverA capability only the consultants know how to run — so it quietly stops being used.
02

Six phases. Designed to end.

Most consultancies are structured to extend the engagement. This one is structured to finish it — every phase carries an exit condition written into the statement of work.

Phase 01 · Frame

Find the real constraint

We spend the first weeks understanding what actually happens, not what the process documentation says happens. Almost every engagement uncovers something that was never in the brief.

Weeks 1–2

Phase 02 · Foundation

The unglamorous layer

Environments, data contracts, access model, evaluation harness. The work that decides whether anything after it survives contact with production.

Weeks 3–6

Phase 03 · Integrate

Into what you already run

Connected to the systems that hold the data and run the work, with the failure paths designed rather than discovered in production.

Weeks 4–10

Phase 04 · Ship

Under real change control

Into production behind the same governance as everything else you run. No parallel universe. No permanent pilot.

Continuous

Phase 05 · Prove

Against the agreed number

Measured against the figure set in Frame. If it did not move, we say so, and we say why. That conversation is the product.

Weeks 9–12

Phase 06 · Hand over

And then we leave

Runbooks, monitoring, paired operation, and a date after which your team runs it without us. The engagement is designed to end.

Weeks 12–14
